# Ví dụ áp dụng · Quy chuẩn JavaScript

## Ví dụ 1

**Yêu cầu:** Dùng $coding-standards review adapter candidate search.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Patch dễ review và kiểm tra ngắn theo phần đổi.
4. Nghiệm thu: Refactor giữ behavior bằng evidence/test phù hợp.; Không trộn require/import ngoài conventions của package hoặc tạo dependency không cần.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
