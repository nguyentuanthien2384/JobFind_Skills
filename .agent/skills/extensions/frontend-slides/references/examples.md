# Ví dụ áp dụng · Trình bày và demo dự án

## Ví dụ 1

**Yêu cầu:** Dùng $frontend-slides lập demo luồng ứng tuyển từ Stitch và source.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Storyboard và demo/slide theo định dạng được giao.
4. Nghiệm thu: Mọi số màn/route/test có nguồn, không cộng duplicate prototype.; Slide giải thích rõ designed/implemented/verified.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
