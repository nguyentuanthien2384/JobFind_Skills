# Ví dụ áp dụng · Vẽ và sửa màn Stitch

## Ví dụ 1

**Yêu cầu:** Dùng $stitch-design vẽ thêm mobile tìm việc trong project JobFind hiện có.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Màn Stitch thật hoặc prompt/spec offline có blocker rõ ràng, metadata và handoff.
4. Nghiệm thu: 37 màn gốc vẫn được giữ; màn bổ sung không trùng screen key.; URL/screen ID do dịch vụ trả về; offline proposal được ghi rõ là chưa xuất lên Stitch.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
