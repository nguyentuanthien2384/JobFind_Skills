# Ví dụ áp dụng · Lưu trữ lịch sử

## Ví dụ 1

**Yêu cầu:** Dùng $archive-memory lưu mốc hoàn thiện thiết kế tìm việc.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Archive, index và context hiện tại gọn nhưng đủ tiếp tục.
4. Nghiệm thu: Archive append-only, không xóa lịch sử để giảm token.; Context mới có đường truy hồi đến evidence gốc.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
