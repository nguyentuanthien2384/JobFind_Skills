# Ví dụ áp dụng · Design system từ mẫu

## Ví dụ 1

**Yêu cầu:** Dùng $design-system trích style JF-036 để vẽ thêm mobile.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu DESIGN.md, token provenance, component/variant matrix và design handoff.
4. Nghiệm thu: Token có nguồn hoặc nhãn proposal; không đổi mọi variant sang một palette khi cần khớp mẫu.; Các states có nhãn và contrast có thể kiểm tra, không chỉ phân biệt bằng màu.
