# Ví dụ áp dụng · Mẫu backend JobFind

## Ví dụ 1

**Yêu cầu:** Dùng $backend-patterns review transaction khi gửi offer.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Backend refactor/patch với owner, consistency và focused tests.
4. Nghiệm thu: Timeout không được mặc định là write chưa xảy ra.; Cache/projection không làm lộ dữ liệu private hoặc chéo tenant.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
