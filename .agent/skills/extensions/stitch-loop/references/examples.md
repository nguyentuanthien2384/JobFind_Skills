# Ví dụ áp dụng · Vẽ và code theo backlog

## Ví dụ 1

**Yêu cầu:** Dùng $stitch-loop vẽ bổ sung các màn ứng viên còn thiếu theo route coverage.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Screens/patch theo backlog, ledger cập nhật và next-prompt có thể tiếp tục.
4. Nghiệm thu: Baton có feature/screen/task/next action và dependency rõ.; Trạng thái designed, implemented và verified được lưu riêng.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
