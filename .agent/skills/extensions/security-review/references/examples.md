# Ví dụ áp dụng · Review bảo mật code

## Ví dụ 1

**Yêu cầu:** Dùng $security-review kiểm tra patch upload PDF cho chat.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Review report và patch được giao, có severity và evidence cụ thể.
4. Nghiệm thu: Tách finding đã chứng minh và giả thuyết cần kiểm tra.; Không đưa token/password/CV thật vào report.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
