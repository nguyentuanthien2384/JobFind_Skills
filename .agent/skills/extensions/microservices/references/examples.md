# Ví dụ áp dụng · Gateway và sự kiện

## Ví dụ 1

**Yêu cầu:** Dùng $microservices kiểm tra pipeline sync sau khi ứng viên nộp CV.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Patch owner/gateway/consumer cùng contract và kiểm tra tương thích.
4. Nghiệm thu: Hợp đồng HTTP/event giữ cùng phiên bản giữa owner và consumer.; Không ghi trực tiếp dữ liệu service khác để bỏ qua consistency.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
