# Ví dụ áp dụng · Quản trị và duyệt nội dung

## Ví dụ 1

**Yêu cầu:** Dùng $admin-moderation code JF-011 theo ManagePost hiện có.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Admin UI/API patch cùng role/target/action matrix.
4. Nghiệm thu: EMPLOYER/COMPANY không được sử dụng endpoint admin dù có UI tương tự.; Thao tác duyệt/từ chối cập nhật thật và có evidence, không chỉ đổi badge.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
