# Ví dụ áp dụng · Kiểm thử và nghiệm thu

## Ví dụ 1

**Yêu cầu:** Dùng $test-release nghiệm thu màn tìm việc và API filters vừa sửa.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Verification report với passed/failed/skipped, logs cần thiết và rủi ro còn lại.
4. Nghiệm thu: Báo cáo chỉ nêu lệnh đã chạy và kết quả thực; không gắn toàn dự án pass từ kiểm tra bộ skills.; Không chạy test gửi thư/mua gói/AI live ngoài phạm vi đã giao.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
