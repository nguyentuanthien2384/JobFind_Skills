## Ví dụ 1

**Yêu cầu:** Dùng $auth-security hoàn thiện Google và GitHub qua Auth0 cho màn đăng nhập.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Patch auth/UI theo đúng provider, ma trận lỗi và kiểm tra phù hợp.
4. Nghiệm thu: Nút provider không hứa live login khi IdP chưa sẵn sàng.; Backend chặn privilege escalation và access chéo tenant dù UI bị sửa.
