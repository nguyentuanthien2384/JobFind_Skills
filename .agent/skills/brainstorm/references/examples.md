# Ví dụ áp dụng · Phân tích ý tưởng

## Ví dụ 1

**Yêu cầu:** Dùng $brainstorm phân tích trang lịch phỏng vấn tổng hợp từ pipeline hiện có.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Idea brief có phương án được chọn, điều kiện nghiệm thu và việc cần khảo sát.
4. Nghiệm thu: Lập luận chỉ ra file source cụ thể hoặc nhãn giả định.; Phương án dùng đúng stack và không phát sinh chức năng ngoài yêu cầu.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
