# /code-ui

## Đầu vào
Yêu cầu hiện tại, source root, feature/screen/variant nếu có; đọc AGENTS.md, .docs/CONTEXT.md và registry. Skills: code-ui, frontend-design (xem mapping trong registry).

## Thực hiện
1. Select screen and reference mode; inspect HTML/PNG.
2. Implement JSX/CSS with component reuse and states.
3. Verify viewport/keyboard/layout and handoff exact mapping.

## Đầu ra và acceptance
UI patch + screen contract evidence. Dùng source hiện hành và contract thật; giữ các thay đổi người dùng. Tách design/code/test status và ghi evidence/lỗi/gap/next task. Khi user giao toàn bộ tính năng, tiếp tục các bước cần thiết đến kết quả đó; không buộc xác nhận từng bước thường lệ.

## Khi bị chặn
Hoàn thành phần độc lập; giữ draft/spec/checkpoint. Nêu đúng công cụ, source hay điều kiện thiếu; không bịa link, endpoint hoặc kết quả kiểm thử.
