# Ví dụ áp dụng · Điều phối dự án

## Ví dụ 1

**Yêu cầu:** Dùng $workflow thiết lập đầy đủ .agent, .docs, .stitch cho source JobFind hiện tại.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Bộ điều phối trong project hoặc patch tính năng đã giao., Chuỗi tài liệu ý tưởng → thiết kế → frontend → backend → API → QA, cập nhật context.
4. Nghiệm thu: Registry giải quyết được mọi skill và mọi tài liệu liên quan.; Bản thiết kế, patch và test có bằng chứng riêng; checkpoint không đánh dấu code hoàn thành chỉ từ một bản vẽ.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
