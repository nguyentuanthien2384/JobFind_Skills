## Ví dụ 1

**Yêu cầu:** Dùng $job-management code wizard JF-021 từ AddPost.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Job CRUD/repost/UI patch và contract/quota checks.
4. Nghiệm thu: Repost không tạo nhiều tin/tiêu quota nhiều lần từ cùng thao tác.; Tin chưa được phép public không xuất hiện trong search vì UI filter.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
