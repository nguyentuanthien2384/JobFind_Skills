## Quy trình chi tiết
1. Chọn screen ID và biến thể; đọc ảnh/code reference, screen contract, STYLEGUIDE và component map. Xác minh design live nếu được yêu cầu cập nhật theo live.
2. Dùng mode match-reference cho yêu cầu giống bản Stitch; dùng JobFind-normalized chỉ khi user yêu cầu chuẩn hóa thương hiệu. Giữ tokens của đúng variant.
3. Tái sử dụng shell, component, hook và service hiện hành. Dịch HTML Tailwind reference thành JSX và CSS/SCSS có scope trong CRA.
4. Tạo default/loading/empty/error/forbidden/submitting/success cần thiết, giữ giá trị form và có thông báo có thể truy cập bằng bàn phím.
5. Với UI hoạt động, nối adapter thật cùng integrate-api; mockup chỉ dùng fixture được ghi rõ và không coi button mock là hoàn thành nghiệp vụ.
6. Đối chiếu screenshot đúng viewport, responsive và interactions; ghi mapping frame → route → files → API → QA trong handoff.

## Quy tắc riêng của feature
- Menu xuất hiện theo permission và company state, không chỉ role.
- Đọc guard ở router cha; permission list rỗng từ parser không chứng minh public.
- Giữ chat, support, candidate và admin shells theo router thật.

## Decision và failure handling
| Tình huống | Xử lý |
| --- | --- |
| source khác snapshot | Đọc file hiện hành, ghi drift, cập nhật plan/catalog; không giữ route/DTO cũ bằng suy đoán |
| ảnh có control chưa có API | Ghi partial/proposal; implement phần đã có và lập owner/contract plan cho phần thiếu |
| 401/403 hoặc company chưa ready | Xử lý session/permission/readiness thật và giữ draft; server vẫn cần enforce |
| write timeout hoặc refresh | Không tự replay; giữ idempotency theo contract và cung cấp retry có chủ đích |
| tool Stitch/Figma không có hoặc bị chặn | Giữ prompt/spec/assets local; nêu phần chưa đưa lên dịch vụ và không bịa link |
| giao diện giống mẫu nhưng mock data | Ghi designed/UI-mock; nối dữ liệu và kiểm tra thật trước implemented/verified |
| test cần DB/IdP/provider chưa có | Chạy kiểm tra độc lập được phép; ghi skipped với điều kiện thiếu |

## Output và acceptance
- JSX/CSS patch, screen handoff, hình đã render nếu preview có sẵn và kết quả kiểm tra.

- Ảnh reference không bị thay bằng một màn tổng quát khác; nội dung không cắt/tràn.
- Dữ liệu và CTA ứng tuyển/duyệt/mua gói tuân thủ quyền thật của source.
