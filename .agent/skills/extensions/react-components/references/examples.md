## Ví dụ 1

**Yêu cầu:** Dùng $react-components tách JobCard và FilterPanel từ JF-036.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Component/container/hook/CSS patch cùng props/state handoff.
4. Nghiệm thu: Component chạy trong CRA hiện có, không yêu cầu Vite/TypeScript mới.; Style không làm thay đổi màn ngoài feature do selector toàn cục.
