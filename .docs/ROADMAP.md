# Roadmap theo lát nghiệm thu

1. Bootstrap registry/tài liệu theo source hiện hành; resolve drift/conflicts.
2. Public/candidate: home/search/detail/login/signup/profile/prepared CV/apply/history/saved/follow, đúng API modes.
3. Employer/company: onboarding/readiness/profile/job wizard/workspace/candidate search/pipeline/interview/offer/chat/packages.
4. Admin: overview/users/jobs/company moderation/catalogs/packages/orders/report/audit; proposals riêng settings/global analytics.
5. Mở rộng responsive/states từ native + Figma V2, design QA và focused functional tests.
6. Nghiệm thu scope đã giao; chuẩn bị rollout/rollback khi user yêu cầu.

Đây là thứ tự gợi ý, không chứng minh các phần đã thực hiện. Ưu tiên yêu cầu hiện tại và reuse source.
