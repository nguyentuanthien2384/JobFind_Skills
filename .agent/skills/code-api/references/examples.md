# Ví dụ áp dụng · Code REST API

## Ví dụ 1

**Yêu cầu:** Dùng $code-api sửa gửi thư mời phỏng vấn cho application đúng công ty.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Patch endpoint đầy đủ, contract, error handling và kiểm tra phù hợp.
4. Nghiệm thu: Endpoint xuất hiện trong router/gateway/contract cần thiết và client gọi đúng.; Không phát lại thao tác ghi tự động sau refresh hoặc khi timeout không rõ kết quả.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
