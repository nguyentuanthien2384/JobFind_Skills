# Ví dụ áp dụng · Đánh giá component tùy chọn

## Ví dụ 1

**Yêu cầu:** Dùng $shadcn-ui đánh giá thay Dialog của modal CV bằng primitive phù hợp.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Compatibility decision hoặc component patch theo phạm vi được yêu cầu.
4. Nghiệm thu: Dependency mới có lý do gắn với yêu cầu cụ thể.; Component hiện hành không bị phá hoặc đổi theme toàn cục.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
