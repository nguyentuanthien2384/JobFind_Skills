# Ví dụ áp dụng · Figma và bàn giao code

## Ví dụ 1

**Yêu cầu:** Dùng $figma-handoff thêm trạng thái lỗi ứng tuyển vào Figma theo JF-024.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Frames/components hoặc handoff được xác minh với node map và QA.
4. Nghiệm thu: Link đúng node và file còn tồn tại; mỗi catalog key có mapping duy nhất.; Bản Figma mục tiêu không bị mô tả là source đã implement.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
