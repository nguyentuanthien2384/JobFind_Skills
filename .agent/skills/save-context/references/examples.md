# Ví dụ áp dụng · Lưu và tiếp tục phiên

## Ví dụ 1

**Yêu cầu:** Dùng $save-context lưu tiến độ vẽ JF-014 và kế hoạch code lịch.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Context hiện tại, feature ledger và nhật ký có evidence, next action.
4. Nghiệm thu: Người tiếp tục biết cần làm bước nào và file nào đọc đầu tiên.; Không gắn DONE cho thiết kế chưa được code hoặc test chưa chạy.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
