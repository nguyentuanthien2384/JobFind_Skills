# Ví dụ áp dụng · Thiết kế hợp đồng API

## Ví dụ 1

**Yêu cầu:** Dùng $api-design mô tả API cho trang lịch tổng hợp proposal.

1. Nạp project context, feature/screen evidence và source root.
2. Áp dụng quy trình của skill vào đúng phần được giao; ghi mode và source gap.
3. Lưu Endpoint contract và compatibility/test plan có bằng chứng.
4. Nghiệm thu: Client phân biệt empty, permission, validation và transient error được.; Đường API của admin có đúng /api/admin prefix.

Output status phải theo bằng chứng thực. Khi chỉ yêu cầu plan hoặc prompt, không đánh dấu implementation hoàn thành.
